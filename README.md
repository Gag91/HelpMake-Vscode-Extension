# HelpMake-Vscode-Extension

Syntax highlighting for [HelpMake](https://github.com/Gag91/Help_Make) build files.

## Features

- Syntax highlighting for `HelpMake.txt` and `.helpmake` files
- Comments (`#`)
- Block keywords (`InputFiles`, `Includes`, `Flags`, `Fetch`, `PreBuild`, `PostBuild`, `Config`)
- Field names (`Compiler`, `Version`, `Output`, `Run`)

## Usage

Just open a `HelpMake.txt` file. Highlighting works automatically.
